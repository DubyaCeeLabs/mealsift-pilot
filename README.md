# MealSift Production Pilot

Simple, account-free weekly meal planning and combined grocery-list PWA.

## Pilot scope
- Add/remove up to 5 meals
- Monday–Friday weekly plan
- Search by recipe or ingredient
- Deduplicated grocery list with compatible quantities summed
- Copy/share grocery list
- Local persistence across reloads
- Reset/recovery control
- Offline cache via service worker
- No backend, account, tracking, paid API, or new-spend dependency

All recipes, code, branding, and assets in this pilot are independently created.
